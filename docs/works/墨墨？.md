# 墨墨露出

关于悬浮面板的任务要求,请在世界书中搜索类任务,将需要的对应整个条目内容复制粘贴进生成任务时的任务偏好

关于悬浮面板的道具购买行为,将会直接插入到变量中,因此如果剧情LLM是不会知道你做了哪些购买行为.

服饰将塞到衣柜中,而道具将塞到背包物品(会有30分钟送达备注),如果说 你想要在正文提及你的购买行为,请自行告知LLM

## 视角自定义

和预设人称视角会有冲突.自行抉择

编写条目"<叙事与描写准则>"中 getvar::墨墨-第一人称的人称

可选人称: 墨墨-第一人称和墨墨-第三人称
