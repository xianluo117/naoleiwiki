## 基本知识

### 什么是反向代理？

反向代理（反代）就是一个中间服务器：先接收你的请求，再转发给真正的目标服务。
你只和这个中间服务器交互，后续流程由它处理。

### 为什么我们需要它？

1. **绕过区域限制**：很多 AI 服务只在部分地区可用，反代能通过可用区域的服务器转发。
2. **简化接入**：把复杂的官方验证（如 OAuth）简化成密码或 API Key。
3. **稳定与分流**：可分发流量、提升稳定性。
4. **成本与风险**：部分服务更贵或有封号风险，第三方反代往往更省心。

### 它是怎么工作的？（以 Claude Cookie 反代为例）

1. **你发送消息**（酒馆）。
2. **请求到反代**（你设置的地址）。
3. **反代代你访问 Claude 官网**（用 Cookie 登录并转发）。
4. **Claude 返回结果**。
5. **反代把结果发回酒馆**。
