## 渲染问题补充

如果已经安装小白X或酒馆助手，以上设置均没有问题，但会同时出现正常渲染和代码块（如下图所示）。

![渲染问题截图](/picture/渲染问题截图.png)

::: warning ⚠️ 解决方法
可能是**酒馆美化与正则冲突**导致的，请尝试：

1. **更换酒馆美化**
2. **清理浏览器缓存**（设置 → 删除浏览数据 → 勾选「缓存的图片和文件」→ 删除数据）

![清理缓存示例](/picture/清理缓存示例.png)
:::
